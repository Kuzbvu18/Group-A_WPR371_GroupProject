# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly to the development team.

## Supported Versions

This project is currently under active development for academic purposes.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Security Measures Implemented

- Password hashing using bcrypt
- Role-based access control
- Environment variable protection
- Session management
- Input validation
- Middleware authorization
